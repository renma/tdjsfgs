Release notes 1.6.6
Released: 2026-02-16
------------------------------------------------------------------------

This release updates and improves key content. Thanks to Alberto for refining
and enhancing it.

Summary:

- On the index page, DJs are now sorted in a way that the most recently updated
  one appears at the top.

- The registration page has been supplemented with an explanatory text intended
  to discourage DJs from signing up without carefully reading what it is about.

- The DJ edit dialog now displays infoboxes permanently to make sure they are
  noticed (and followed...).
  
- Finally, the tdjs script and the CSS file received further small
  improvements, and the links page was updated as well.
