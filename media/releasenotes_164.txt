Release notes 1.6.4
Released: 2026-02-02
------------------------------------------------------------------------

The main focus of this release is a change in the /more section and an update
regarding DJs with a Milonga count of 0 (hidden DJs).

For both cases, it is now guaranteed that the data is never publicly
accessible, even if someone obtains direct links to the resources. The data has
been moved to the /media directory (which is excluded from the web server) and
is only delivered when an ADMIN_USER (DJ Albero or DJ René) is logged in. For
all other cases, the application server responds with error 404.

As part of this update, some cleanup and improvements were also made:

- <tdjs> script simplified (removed obsolete <doc> parameter).
- Used data (png, pdf, etc.) moved from RESOURCES to /static and /media.
- Logfile view removed (now only availabe after ssh-login to uberspace).
- force_disable_debug allows starting the local server without debug mode.
- Updated cron job. It now checks every minute whether the application needs to
  be restarted and sends an email notification if this occurs (see
  <checkserver.sh>).
